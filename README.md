# EventWaa - Event Discovery & Ticketing Platform for Uganda

EventWaa is a web platform that helps people in Uganda discover events, view event details, and book tickets online. Organizers can also create and manage their events.

Live Demo: https://EventWaa.com

## Features
- Discover upcoming events in Uganda
- View event details, location, date and ticket prices
- Book tickets online
- Organizer dashboard to create and manage events
- User authentication (Login / Register / Reset Password)
- Responsive design for phone and laptop

## Tech Stack
- Frontend: React + Vite(hosted on vercel)
- Backend: python  + flask (hosted on railway)
- Database: supabase(postgresql)
- Deployment: Vercel

## How to Run Locally
1. Clone the repo: git clone https://github.com/eventwaa-ug/EventWaa
2. Install dependencies: npm install
3. Start frontend: cd frontend && npm run dev
4. Start backend: cd backend && npm start
